Save the app icon here as:  AppIcon-1024.png

Requirements (App Store):
- Exactly 1024 x 1024 pixels, PNG
- NO transparency / alpha channel. Fill the whole square (the cream #F6EFDD
  background is fine); iOS applies the rounded-corner mask itself.
- No layers, no extra padding beyond what you want visible.

After adding the file, run `xcodegen generate` again so Xcode picks it up.
